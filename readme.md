Job.tc
Welcome to the Job.tc Hiring System project! This system is designed to streamline the hiring process for companies, enabling efficient management of job postings, applications, and candidate evaluations. This hiring system has a unique feature called Instant Interview which automatically matches an applicant to an interviewer instantly upon their submission of their application details to the system through WebRTC.
Features
    • Job Postings Management: Create, update, and delete job postings.
    • Application Tracking: Track applications submitted for each job posting.
    • Candidate Evaluation: Evaluate candidates and update their status throughout the hiring process.
    • User Roles: Different access levels for administrators, recruiters, and candidates.
    • Notifications: Email notifications for application updates and interview schedules.
    • Reporting: Generate reports on hiring metrics and candidate statistics.
    • Instant Interview: Through webrtc using the Janus Gateway, applicant and interview are seamlessly paired up depending on the job upon applicant’s submission of their applicant details such the resume and cover letter.
Technologies Used
    • Backend: Laravel 8
    • Frontend: Laravel
    • Database: MySQL
    • Authentication: Basic Laravel Authentication
    • Email: Mailgun API
    • Deployment: Digital Ocean
